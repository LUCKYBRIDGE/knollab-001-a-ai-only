# Version 1 기준 기록

Version 1은 특수학교 학생이 카페에서 음료 주문 과정을 가능한 범위에서 혼자 연습할 수 있도록 만든 최초 완성본이다.

## 보존 기준

- 실행 파일: `index.html`, `style.css`, `script.js`
- 독립 실행 스냅샷: `versions/v1/`
- 보존 브랜치: `version-v1`
- 핵심 기술: 순수 HTML, CSS, JavaScript
- 외부 프레임워크, 별도 백엔드, 데이터베이스를 사용하지 않는다.
- 데스크톱과 태블릿에서 사용할 수 있어야 한다.

## 설계 판단 기준

Version 1 당시 작업 기준은 다음과 같다.

1. 사용자가 처음 접했을 때 무엇을 해야 하는지 쉽게 알 수 있어야 한다.
2. 선택 가능한 요소와 선택된 상태가 분명해야 한다.
3. 현재 주문 단계와 다음 행동을 이해하기 쉬워야 한다.
4. 잘못 선택했을 때 이전 단계로 돌아가 수정할 수 있어야 한다.
5. 시작부터 주문 완료까지 실제로 조작 가능한 하나의 흐름으로 이어져야 한다.
6. 같은 의미의 버튼과 상태 표현은 일관되어야 한다.
7. 불필요한 정보와 조작을 줄이고 큰 선택 요소를 사용한다.
8. 실제 카페 주문 연습이라는 목적에 직접 도움이 되는 기능을 우선한다.

## Version 1 실행 흐름

`시작 → 음료 선택 → 온도·크기·수량 선택 → 매장/포장·결제 선택 → 주문 확인 → 필요 시 수정 → 주문 완료 → 다시 시작`

이 문서는 Version 2 작업 전에 Version 1의 설계·구현 판단 기준을 복구 가능하게 남기기 위한 기록이다. Version 1의 실행 파일 자체는 `versions/v1/`과 `version-v1` 브랜치에 별도로 고정되어 있다.
