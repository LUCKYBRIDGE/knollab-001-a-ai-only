# Version 3 검토 및 개선 기록

## 1. Version 2 보존 확인

Version 3 작업 시작 전 다음 상태를 확인했다.

- `versions/v2/`에는 `index.html`, `style.css`, `script.js`, `v2-overrides.css`가 보존되어 있다.
- Version 2 스냅샷 커밋은 `79603e14ede04fc2d00bfc4b34ceb24d7118fd65`이다.
- `version-v2` 브랜치가 위 커밋을 가리키므로 Version 2 전체 리포지토리 상태를 복구할 수 있다.
- Version 3 작업에서는 `versions/v1/`, `versions/v2/`를 수정하지 않는다.
- Version 2 당시 리포지토리 문서 상태 역시 `version-v2` 브랜치에서 함께 확인할 수 있다.

## 2. Version 3 개선 원칙

Version 2의 기능 범위와 다음 핵심 흐름을 유지한다.

`시작 → 음료 선택 → 추가 선택 → 매장/포장 선택 → 주문 확인 → 필요 시 수정 → 주문 완료 → 다시 시작`

새 기능의 수를 늘리지 않고 이해하기 쉬움, 조작하기 쉬움, 상태의 명확성, 실수 후 복구, 반복 조작 감소, 화면·인터랙션 일관성을 우선한다.

## 3. 실제 구현 검토에서 확인한 문제

1. 주문 확인 화면에서 온도 정보가 `음료` 행에 포함되어 있으나 해당 행의 수정 버튼은 1단계인 음료 선택으로 이동해 정보와 수정 위치가 일치하지 않았다.
2. 주문 확인 화면에서 일부 항목을 수정하면 이미 유효한 후속 선택까지 다시 거쳐야 해 불필요한 반복 조작이 발생했다.
3. 주문 완료 화면에서 상단 `읽어주기`와 완료 카드의 `주문 문장 듣기`가 함께 보여 같은 목적의 음성 조작이 중복되었다.
4. 진행 상태는 막대로 표시되지만 현재 단계라는 의미가 텍스트에서 충분히 강조되지 않았다.
5. 선택 가능 카드의 기본 경계가 약해 선택 요소와 일반 정보의 구분을 더 명확하게 할 필요가 있었다.
6. 선택 완료/미완료 안내가 색에 주로 의존해 기호와 문구를 함께 제공할 필요가 있었다.
7. 1단계에서 시작 화면으로 돌아간 경우 기존 선택은 유지되지만 다시 시작하는 것처럼 보이는 문구 때문에 상태 유지 여부가 명확하지 않았다.
8. 일부 선택 안내 문구에서 한국어 조사 결합이 자연스럽지 않은 경우가 있었다.
9. 초기화 대화상자에서 키보드 Tab 이동이 대화상자 바깥으로 빠질 수 있었다.

## 4. Version 3 반영 내용

- 주문 확인 행을 `음료`, `온도·크기·수량`, `매장·포장`으로 재구성해 정보와 수정 단계가 일치하도록 했다.
- 확인 화면에서 수정할 때 기존 후속 선택이 여전히 유효하면 `주문 확인으로 돌아가기`를 통해 반복 단계를 건너뛸 수 있게 했다.
- 수정 중임을 안내하는 문구를 추가하되 기존 선택값은 유지한다.
- 주문 완료 화면에서는 상단 읽어주기를 숨기고 주문 문장 듣기만 남겨 중복을 제거했다.
- 진행 영역에 `지금:` 표현과 progressbar ARIA 상태를 추가했다.
- 선택 카드의 기본 경계와 선택 경계를 강화하고 `✓ 선택함` 상태를 계속 사용한다.
- 상태 안내에 `!`와 `✓` 기호를 함께 사용해 색상만으로 상태를 구분하지 않도록 했다.
- 1단계에서 시작 화면으로 돌아온 경우 `계속 연습하기`와 선택 유지 안내를 표시한다.
- 음료·온도·크기·매장/포장 선택 후 안내 문구를 자연스러운 한국어 표현으로 보정했다.
- 초기화 대화상자 안에서 Tab/Shift+Tab 포커스가 두 버튼 사이를 순환하도록 했다.

## 5. 직접 실행 검증

Headless Chromium에서 데스크톱(1280×900)과 태블릿(900×1100) 크기로 직접 실행해 확인했다.

- 시작 화면에서 연습 시작
- 음료 선택 및 선택 상태 표시
- 온도 선택, 크기 선택, 수량 변경
- 차가운 음료만 가능한 메뉴의 온도 자동 선택
- 매장/포장 선택
- 주문 확인 정보와 총액 표시
- 주문 확인에서 음료 수정 후 필요한 옵션 재선택
- 기존 매장/포장 상태를 유지한 채 주문 확인 화면으로 바로 복귀
- 주문 완료
- 완료 화면의 중복 음성 버튼 제거
- 다시 연습하기로 초기 상태 복귀
- 1단계에서 시작 화면으로 돌아갔을 때 기존 선택 유지와 `계속 연습하기` 표시
- 초기화 모달 열기 및 Tab 포커스 순환
- 두 화면 크기에서 가로 오버플로 없음
- 실행 중 JavaScript 오류 없음

## 6. Version 3 파일 구조

루트 실행 파일은 기존 `index.html`, `style.css`, `script.js`, `v2-overrides.css`를 유지하고 Version 3의 최소 개선 레이어인 `v3-overrides.css`, `v3.js`를 추가한다.

최종 확정 상태는 `versions/v3/`에도 같은 실행 구성으로 보존하고, 별도 Version 3 브랜치로 복구 가능하게 유지한다.
